# F-Droid Panel

A self-hosted web dashboard to manage one or more [F-Droid](https://f-droid.org) repositories from your browser: add apps by drag and drop, publish new versions, edit metadata, icons and screenshots, and publish the signed index, without using the command line.

> **Status: design phase.** Nothing is usable yet. See the [architecture](docs/ARCHITECTURE.md) and the [roadmap](docs/ROADMAP.md).

F-Droid Panel is an independent project. It is not affiliated with or endorsed by the F-Droid project.
